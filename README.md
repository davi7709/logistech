GERENCIAMENTO DE ESTOQUE
Este projeto é uma aplicação web para gerenciamento de estoque, desenvolvida para controlar a entrada e saída de produtos, acompanhar o nível de estoque e realizar operações básicas como adição, remoção e consulta de produtos. O sistema permite aos administradores manterem o controle sobre o estoque de maneira fácil e eficiente.

Funcionalidades:
Cadastro de Produtos: Adicionar novos produtos ao estoque com informações detalhadas (nome, descrição, preço, quantidade).
Controle de Estoque: Acompanhar o nível de estoque em tempo real, com a capacidade de adicionar ou remover produtos.
Consulta de Produtos: Buscar produtos por nome, categoria ou código de barras.
Relatórios de Estoque: Gerar relatórios com o status do estoque, incluindo produtos com baixo estoque ou vencidos.
Administração de Categorias: Organizar os produtos por categorias (exemplo: eletrônicos, roupas, alimentos, etc).
Gestão de Usuários: Sistema de login e permissões para diferentes tipos de usuários (administrador, gerente, etc).
Tecnologias Utilizadas

Backend:

Java
Spring Boot
Spring Data JPA

Hibernate
Frontend:

HTML/CSS/JavaScript
